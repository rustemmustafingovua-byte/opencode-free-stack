# Замеры

_darwin arm64, Node 26.12.0 — замеры сделаны на этой машине, повторы 3–5, в таблице медиана._

| Инструмент | Что замеряли | Медиана, мс | Комментарий |
|---|---|---|---|
| prompt-budget | 300k символов → 78000 токенов | 7.2 | подсчёт токенов, без сетевых запросов |
| tool-schema-lint | схема из 3 параметров — полный анализ | 183.9 | включая запуск процесса |
| mcp-doctor | проверка всех настроенных MCP-серверов | 15319.5 | запуск процесса + опрос серверов |
| agent-cost-guard | проверка бюджета в прокси (GET /health) | 1.2 | задержка добавляется к каждому запросу |
| free-web-mcp | поиск в Hacker News (живая сеть) | 1296.2 | реальный сетевой запрос |
| x402-priceboard | сбор цен по открытым x402-эндпоинтам | 473.2 | живая сеть, без единой транзакции |
| lumen-chain | блок с транзакцией: предложение + подпись + проверка | 0.799 | среднее на блок, 100 блоков |
| lumen-chain (VM) | исполнение контракта: чтение и запись в хранилище | 0.003 | среднее на вызов, 100 000 вызовов |

Как повторить:

```bash
node scripts/benchmarks.mjs --save
```
