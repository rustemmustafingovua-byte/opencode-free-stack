opencode-free-stack

Route every request to a model that costs $0 — and fall back automatically when a provider runs dry.

Free model tiers do not fail randomly. They fail in three specific ways: a per-minute cap, a daily token pool, and a model weight that drains that pool two to four times faster than the token count suggests. This package knows all three and treats them as what they are — a routing problem, not a crash.

What it does

Registry of free models28 models across OpenCode Zen, GitHub Copilot, BeatAPI and APInex, with their real limits.
RPM limiterSliding window per provider, so a 429 is waited out instead of retried into.
Pool accountingTokens are charged as tokens x weight, so the router knows when a provider is done for the day.
Fallback router402, 429, auth and upstream errors are classified, and the request moves to the next free model.
OpenCode pluginContinues the same turn on another model when the current one is out of quota.
Self-refreshing registrymodels.json is rebuilt every six hours from the live catalogues.

How it works

  1. Build a chain: the preferred model of each provider first, then its other free models.
  2. Wait out the provider's RPM limit with a sliding window.
  3. Send, then classify the failure: rate_limit, quota_exhausted, auth, upstream.
  4. Charge the daily pool as tokens x weight and remember the result.
