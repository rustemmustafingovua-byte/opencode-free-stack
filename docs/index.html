opencode-free-stack

Route every request to a model that costs $0. Fall back automatically when a provider runs dry.

npm install -g opencode-free-stack
ofs status

What it does

Knows the limitsRPM caps, daily token pools and model weight, per provider.
Falls back402, 429 and auth errors move the request to the next free model.
Tracks the poolTokens × weight, so it knows when a provider is done for the day.
